# Connector verification matrix

Evidence below names retained tests and their boundaries. PostgreSQL lifecycle tests use controlled provider/storage collaborators; OAuth tests use a local signed-token fixture. Browser tests exercise the real frontend with routed responses, not live Google acceptance. The [historical pre-cutover Google run](../increments/active/google-drive-structured-ingestion/plan.md#live-google-acceptance-after-fresh-authorization) covered native content and restart recovery but does not verify the later owner-app/explicit-link cutover. Current gates and the fresh real owner-app consent, Source replacement and three-link ingestion are recorded in the [latest ledger](../increments/active/google-drive-structured-ingestion/plan.md#owner-app-and-interface-verification). JetBrains inspection was unavailable; no IDE-clean claim is made.
