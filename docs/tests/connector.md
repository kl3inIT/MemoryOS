| Scoped Source projections expose exactly `upload` and `reindex`; scoped managers cannot create Sources, replace associations, remove items, delete Sources, or query association options | `SourceApiIntegrationTest.enforcesScopedSourceHttpSurfacesAndImmediateAssociationRevocation`; `PostgresSourceLifecycleTest.scopedManagerReadsAndManagesOnlyAssociatedSources` |
| Source creation defaults an absent/empty Group list to Admin; non-default Group IDs must belong to the Tenant and fail atomically when invalid; association replacement rejects an empty set | `PostgresSourceLifecycleTest.sourceCreationAssociatesAdminByDefaultAndRejectsUnknownGroupsAtomically`; `SourceApiIntegrationTest.enforcesScopedSourceHttpSurfacesAndImmediateAssociationRevocation`; `V16__create_source_group_grants.sql` |
| Only global `SOURCES_MANAGE` can query Group options or replace Source–Group associations; replacement immediately removes scoped list/detail/operation access | `SourceApiIntegrationTest.enforcesScopedSourceHttpSurfacesAndImmediateAssociationRevocation`; `PostgresSourceLifecycleTest.scopedManagerReadsAndManagesOnlyAssociatedSources` |

| Connector Source lifecycle, projections, locks, and IAM association joins remain concrete JDBC repositories owned by Connector; IAM exposes identifiers/authorization rather than JPA entities | `PostgresSourceLifecycleTest`; `CoreDependencyRulesTest.persistencePackagesAreVisibleOnlyToTheirOwningCapability`; Modulith verification |
