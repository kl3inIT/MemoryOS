The persistence suite runs the production Flyway schema with IAM JPA lifecycle entities and concrete SQL projections. PostgreSQL supplies the row-lock and mixed JPA/JDBC transaction boundary; browser sessions remain JDBC-backed but store only the Actor principal. API integration uses the real security composition and OIDC exchange. This matrix follows accepted [ADR 0007](../decisions/0007-unified-jpa-iam-and-group-authorization.md); Group/Source capability matrices own their detailed delegation and association cases.
