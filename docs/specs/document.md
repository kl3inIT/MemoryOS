# Document capability contract

Document owns normalized durable knowledge independently of provider implementation. A Document is Tenant-scoped and either ELIGIBLE or INELIGIBLE. DocumentVersion is immutable and records bounded normalized text, safe title, detected media type, source-content SHA-256, and metadata.

`DocumentCommandPort.publish` creates a Document/version or appends a version keyed by source hash and processing profile to the currently mapped Document. Pair serialization and database uniqueness make publication deterministic. Connector owns provenance mappings; Document never imports Connector or Ingestion types.

Structured extraction stores one private, SHA-256-verified JSON object under `extracted/<tenant>/<artifact>/document.json`. `document_versions` references the artifact and records its processing profile; bounded normalized text remains a compatibility projection. Existing versions retain `legacy-tika-v1` and need no synthetic artifact backfill. The artifact schema `memoryos-extraction-v1` orders blocks with kind, text, optional heading level, table cell offsets/header flags, and source-provided page/bounding-box provenance. Image data is embedded in this self-contained artifact, not stored at an externally fetched URL.

Before extraction, `document_processing_attempts` pins the profile for the operation. After extraction it pins the output hash. Retry with a different profile or output fails rather than overwriting completed content. Artifact rows are staged before object writes, marked write-complete only after PUT and checksum inspection, and adopted in the same transaction as version publication and connector completion. Stale publication rolls back adoption. A referenced artifact is never eligible for cleanup. Unreferenced completed writes are removed; expired uncertain writes retain a deletion tombstone and are swept daily so a late PUT cannot become untracked. The profile ledger is retained as operation audit metadata; unresolved write tombstones deliberately have no finite deletion deadline.

When Connector removes provenance, `DocumentCommandPort.removeUnreferenced` hard-deletes Document/version content only after no live mapping remains. Current-version foreign keys are cleared before version deletion. MEM-35 exposes no retrieval HTTP endpoint, embeddings, chunks, or citations.
