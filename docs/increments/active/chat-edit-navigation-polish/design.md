## assistant-ui elements follow-up (owner goal 2026-09-13, item 3)

The owner reshaped the remaining element work after UI review: no tool-call group, retrieval chunk or reasoning surfaces (reasoning is backlog and would be collapsed by default); Web search keeps its localized progress without tool names or arguments. Each element below is delivered and committed separately.

- **Regenerate with another model.** Next to the existing Regenerate button, an `ActionBarMorePrimitive` menu lists the same authorized catalog as the model picker (shared query key) and calls the existing REST regenerate command with that `modelConfigurationId`. It does not use the upstream RegenerateMenu element (no Escape/outside-click handling) or `aui.message.reload`, because MemoryOS regeneration is a saved server command that creates a branch. The composer's model choice is unchanged; only a server fallback updates it, as for other turns. The menu is shown only when more than one model is available.
- **Timestamps and duration.** `ChatMessage.createdAt`/`finishedAt` are already in history; `toUiMessages` now carries `finishedAt`. A live reply takes `createdAt` from the transport's accepted send or from the restored RUNNING message, and `finishedAt` from the polled saved message or, for a terminal SSE outcome, the browser clock (bounded skew; history after reload is server-authored). The answer action bar shows the local time and duration on hover or keyboard focus, with the full date as a tooltip. No backend or stream contract change.
- **Dictation** is withdrawn: the Web Speech adapter sends audio to the browser vendor's recognition service, outside MemoryOS. The owner deferred it to [MEM-91](https://linear.app/memory-os/issue/MEM-91).
- **Draft restore.** Unsent composer text is stored in `sessionStorage` under `memoryos.chat.draft:{actorId}:{remoteId|new}` and restored when the composer mounts, following the per-tab model preference convention. It never outlives the tab; sending or clearing the text removes the entry. Visited conversations already keep their composer state while switching, so only reloads needed this.
- **Quote and image preview** follow in separate commits; stopped runs ("Đã dừng") and the empty state (heading plus starters) already exist and receive no new UI.
