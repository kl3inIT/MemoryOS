# Brief student-style writing

Write like a student explaining their own diagram after completing it.

- State what the element does in the system.
- Use one short sentence per actor, use case, or entity.
- Prefer plain verbs: searches, stores, sends, records, checks, manages.
- Avoid filler such as “This comprehensive diagram illustrates…”.
- Avoid claims that are not visible in the paper or diagram.
- Do not repeat the element name as a definition.
- Keep terminology consistent with labels in the diagram.
- Use present tense.

Good:

> Stores the reservation request and its current status.

Too mechanical:

> The Booking entity is an entity that is responsible for comprehensively managing all booking-related information within the overall system.
